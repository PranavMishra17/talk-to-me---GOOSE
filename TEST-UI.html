2. Start it

All commands run in PowerShell from E:\talk to me... Goose. Check you're on the latest main first:

git pull

Mock: no keys, no credits

$env:GOOSE_MOCK=1; uv run uvicorn app.api:app --port 8000

Real: one terminal each

uv run python -m app.worker dev
$env:GOOSE_PERSONA='maya'; uv run python -m app.worker dev
Remove-Item Env:GOOSE_MOCK -ErrorAction SilentlyContinue; uv run uvicorn app.api:app --port 8000

The Maya terminal is needed only for step 4.6 and for rooms opened for Rohan. Open everything in Chrome at http://localhost:8000. Browsers allow mics only on localhost or https, so a phone on your Wi-Fi can't use the mic.

5. If something breaks

You seeDo this
"Agent offline"The worker isn't running. Run the command shown and open a new room; a room opened while it was off stays empty. Rooms for Rohan need the Maya terminal.
"Can't reach the room"The room has closed or never existed. Open a new one.
"Backend not running: POST /rooms"uvicorn is down or crashed. Check its terminal. An owner or personality the server doesn't know also shows this.
"Allow the microphone"Click the icon at the left of Chrome's address bar, allow the mic, join again.
Worker crashes on noise_cancellationRun uv sync --extra nc. The main folder already has it.
A code change did nothingRestart the worker and uvicorn. Neither reloads on its own here.
Greeting ignores Join asJoin within 5 minutes of opening the room, and check the room is for Pranav. Only his contacts are known.
